# Constituency Pulse

A constituency-level social-media sentiment and influence-tracking **technical demo** for Indian
Lok Sabha seats — real historical election data drives swing-tier classification, and every
social-platform layer (accounts, posts, engagement, growth history, sentiment/topic/narrative
analysis, the cross-account influence graph, cross-platform amplification) is fully synthetic,
generated by deterministic code in `src/data/mock/`. Built from
`docs/PRD_Social_Sentiment_Constituency_Platform.pdf`.

**Why fully synthetic**: attaching computed sentiment/narrative scores to real named creators —
even genuinely computed rather than fabricated — is too close to the defamation/reputational risk
the source PRD's own Section 7 warns about for a link meant to be shared around, and calling a
live scraper/API integration a "demo" invites the platform-ToS and DPDP obligations Section 7
describes without the legal review that would need to precede a real deployment. So this build has
**no live platform APIs, no LLM calls, and no database** — nothing here is a real person, a real
account, or a real post. It exists to demonstrate what the PRD's analytics look like end to end:
connected-account universe across YouTube/X/Instagram/Facebook, engagement leaderboards, growth and
sentiment-shift alerts, and the PRD's "Constituency Intelligence Graph" as an interactive network
view. See `/methodology` in the running app for the full breakdown of what's real (election
results, boundaries, Digital Engagement Index) vs. synthetic (everything social-platform-related).

## Local development

```bash
npm install
npm run dev
```

No environment variables are required — the app runs immediately with zero setup. The only
optional variable is `SITE_PASSWORD` (see `.env.example`), a shared password for the site-wide
login gate (`src/proxy.ts`) if you want to put a password in front of a shared link; leaving it
unset fails open (no login required).

## Deployment (Vercel)

1. Push this repo to GitHub.
2. Import it in Vercel ([vercel.com/new](https://vercel.com/new)) or run `vercel --prod` from this
   directory.
3. Optionally set `SITE_PASSWORD` in Vercel's Project Settings if you want the login gate active.

## Stack

Next.js 16 (App Router, TypeScript) · Tailwind v4 + shadcn/ui (`base-nova` style) · Recharts ·
`react-force-graph-2d` (influence/network graph) · react-simple-maps (real India constituency
boundaries, no map API key needed). No database, no LLM API, no live platform APIs — every
social-platform data module lives under `src/data/mock/`.
